Karriere

Karriere bei CBDYNE.

Wir rekrutieren über Stellenausschreibungen und per E-Mail. Bewerber melden sich, indem sie auf die Ausschreibung oder Nachricht antworten, die sie erhalten haben.

Warnung vor Recruiting-Betrug

Im März 2024 wurde uns bekannt, dass Betrüger sich als CBDYNE ausgeben und unter Verwendung unseres Namens, Logos und unserer Marke gefälschte Einladungen zu Vorstellungsgesprächen und gefälschte Stellenangebote an Jobsuchende senden. Eine Nachricht, die unseren Namen oder unser Logo trägt, ist kein Beweis dafür, dass sie von uns stammt.

Bevor Sie antworten, auf einen Link klicken oder persönliche Daten weitergeben, bestätigen Sie jede Nachricht, die angeblich von CBDYNE stammt, indem Sie sich direkt an careers@cbdyne.com wenden.

Nachricht überprüfen

Sie sind unsicher, ob eine Nachricht von uns stammt?

Schreiben Sie an careers@cbdyne.com, und wir bestätigen Ihnen, ob eine Recruiting-Nachricht mit dem Namen CBDYNE echt ist.

careers@cbdyne.com

Bitte senden Sie keine Ausweisnummern, Bankdaten oder Steuerformulare, wenn Sie uns um die Überprüfung einer Nachricht bitten.

So erkennen Sie eine gefälschte Nachricht

  • Sie verwendet den Namen oder das Logo von CBDYNE, doch Sie können sie nicht über careers@cbdyne.com bestätigen.
  • Sie stammt von einer täuschend ähnlichen Adresse, die unseren Namen nachahmt, oder von einem kostenlosen Webmail-Konto.
  • Sie bietet eine Stelle ohne echtes Vorstellungsgespräch an oder drängt Sie zu schnellem Handeln.
  • Sie verlangt Ausweisnummern, Steuerformulare oder Bankdaten, bevor Sie den Absender überprüft haben.

Wenn Sie eine solche Nachricht erhalten

  1. Antworten Sie nicht, klicken Sie keine Links an, öffnen Sie keine Anhänge und senden Sie keine Informationen.
  2. Leiten Sie die Nachricht an careers@cbdyne.com weiter, damit wir bestätigen können, ob sie echt ist.
  3. Melden Sie sie der Jobbörse, auf der Ihr Lebenslauf veröffentlicht wurde.

Forschungsziel

Wir verfolgen ein separates CBD-Forschungsprogramm im Zusammenhang mit PTSD. Dies ist ein Forschungsziel und keine Behauptung, dass CBD nachweislich PTSD verhindert, behandelt oder heilt.

Das CBD-Programm ist von unserem Kratom-Programm sowie von unserem Großhandels- und Private-Label-Geschäft getrennt.

Was noch nicht belegt ist

  • Dass CBD eine anerkannte Behandlung für PTSD ist.
  • Dass ein CBDYNE-Produkt von der FDA zugelassen oder für die Behandlung von PTSD verfügbar ist.

Evidenzstandard

Wir stellen kein Prüfprodukt von CBDYNE als von der FDA zugelassen, klinisch erwiesen oder für die Behandlung von PTSD, Opioidgebrauchsstörung oder einer anderen Krankheit verfügbar dar.

Medizinischer und regulatorischer Hinweis: Nichts auf dieser Seite ist medizinische Beratung, eine Empfehlung zur Anwendung von Kratom oder CBD oder eine Einladung zur Teilnahme an einer klinischen Studie. Beenden oder ändern Sie eine verordnete Behandlung nicht aufgrund dieser Informationen. Wenden Sie sich bei medizinischen Entscheidungen an eine qualifizierte medizinische Fachkraft.

Accesibilidad

Acceso para todos.

Nos esforzamos por que este sitio web pueda ser utilizado por el mayor número posible de personas, incluidas las que utilizan tecnología de asistencia.

Nuestro enfoque

Este sitio web está diseñado con HTML semántico, navegación con teclado, indicadores de foco visibles, navegación de salto, etiquetas descriptivas, diseños adaptables, compatibilidad con movimiento reducido y colores de alto contraste. Nuestro objetivo es cumplir con el nivel AA de WCAG 2.2, y la mayor parte del texto supera la relación de contraste AAA, más estricta.

La conformidad de accesibilidad aún no ha sido auditada de forma independiente, y esta declaración no constituye una afirmación de conformidad total con WCAG. Algunas herramientas, navegadores o tecnologías de asistencia de terceros pueden comportarse de manera diferente.
